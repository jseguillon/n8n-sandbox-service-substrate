# Archived Substrate v0.4 files

These files supported an early local compatibility test with the Substrate v0.4
API. They are not a supported installation path. The current n8n integration and
deployment templates use the Substrate v1 API. See the active
[deployment documentation](../../../substrate/README.md).

The old test instructions were removed because they depended on a temporary
source branch, local image tags, and cluster-specific setup. The archived
manifests and patch are retained for reference only.
